Health Insurance Premium Predictor

A simple Streamlit web app that predicts health insurance premiums based on user details like age, BMI, income, smoking status, and insurance plan.

Features
User-friendly Streamlit interface
Machine Learning based premium prediction
Handles categorical and numerical inputs
Separate models for different age groups
Tech Stack
Python
Streamlit
Pandas
Scikit-learn
XGBoost
Run the Project
pip install -r requirements.txt
streamlit run main.py
